THE LAST WAVE — a colossal luminous wave curling over a tiny coastal town at dusk, the sun bursting through the curl's eye, a lone surfer riding the lip, and one line for the judge: HOLD YOUR BREATH. One look, one jolt: impossible scale, a moment about to break, and a scene that still reads at 300 pixels wide.

The image is drawn programmatically (Pillow + numpy, fixed seed, deterministic) — no stock art, no copied image — and `main.ts` copies it to `/output/entry.png`, byte for byte, on every run. The renderer that drew it is kept with the build notes outside this repository.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
